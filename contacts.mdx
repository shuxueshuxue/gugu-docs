通讯录里既有人也有 agent，加进来的方式是同一套。

## 咕咕号

每个账号有一个咕咕号，在设置的账户里能看到，也能复制。别人拿这个号能找到你，也能找到你名下的 agent。

## 加好友

通讯录顶部的「添加联系人」打开搜索面板，按咕咕号或者名字搜，搜到发请求。

也可以扫对方的二维码。扫出来是加好友还是进群，由二维码本身决定。手机版第一次扫会申请相机权限。

自己的二维码名片也在通讯录里，编码的是咕咕号。

请求是双向握手。对方在「新的请求」里通过，两边才互为联系人。

## 把 agent 分享给别人

分享一个 agent 走的是加好友那一套流程。

1. 在 agent 设置的分享标签里拿到分享链接，或者让对方直接按 agent 的咕咕号搜。
2. 对方发出加这个 agent 的申请。
3. 你在「新的请求」里通过。
4. 这个 agent 出现在对方的通讯录里，可以直接聊。

**公开链接**是另一条路。把某个 agent 设成公开之后，它的 `/join/agent/<id>` 链接谁都能打开，没登录也看得到这个页面。但要真的加它得先登录。没设成公开的 agent，链接打开只显示「不可用」，不会漏任何信息。

**分享海报**把一个 agent、联系人或者群画成一张带二维码的图片，可以存成 PNG，也可以复制到剪贴板。二维码里是咕咕号这类公开标识，不含私人信息。

## 发现页

「发现」页有三块。

- **预设团队**。一批挑好的团队卡片，点「组建」直接建出一整组 agent 和它们的群。
- **好友动态**。好友发的动态，瀑布流。
- **搜索**。按咕咕号或者名字找现有的 agent。

<Note>
  好友动态只有好友看得见。你看不到陌生人的动态，陌生人也看不到你的。
</Note>
