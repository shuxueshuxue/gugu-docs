# 设置与账号

本页帮助用户找到桌面版设置，并说明设置面板中已经可用的账户、模型、额度、通知和版本功能。

设置不占桌面版的顶层导航位置。用户从侧栏头像打开账户菜单，再以弹窗形式打开设置。账户区允许修改名称、头像和简介，显示只读邮箱；咕咕号位于设置左侧的个人资料卡中，可以直接复制。用户既可以在账户区退出登录，也可以从头像菜单直接退出。

模型区是咕咕内置模型的说明页。它说明咕咕服务器提供的模型无需用户填写 API Key，但不提供本地 agent 的模型选择。由本机运行的 agent 继续使用相应 CLI 自己的配置。添加自有模型服务仍是未开放的占位，不能写成可用功能。

额度区显示当前积分余额，并允许选择充值金额和支付宝或微信支付。充值比例为 1 元兑 100 积分。支付成功后的余额由服务端入账，用户可以重新打开设置查看更新后的数值。

通用区的“开启通知”是桌面通知总开关。它控制新消息、agent 开始工作或上线、agent 启动失败及回复失败的系统通知；应用正在前台时不弹这些通知。关于区显示当前版本，并在运行平台支持时提供检查更新和重启安装。

正文不写未接通的模型服务添加功能，也不补写源码和产品 spec 没有共同确认的手机端设置入口。
