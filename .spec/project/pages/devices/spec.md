# devices

面向需要决定 agent 在哪里运行的用户，说明设备的登记、在线状态、运行位置和当前可用的管理操作。

本页保证：

- 桌面端登录后自动登记设备；设备列表入口、显示字段、改名和删除规则与当前界面一致。
- 本地设备的在线状态由最近一次定期联络决定；正常退出会停止本地 agent 并报告离线，断电或断网后则在在线时效到期后显示离线。
- 只有在线的自有设备可以创建本地 agent；咕咕云常在线且只运行云端 Agent。
- 本地 agent 使用其所在电脑的文件系统。当前创建界面不提供工作目录选择，不把旧的目录选择器写成现有功能。
- 设备相关设置只写当前可见入口。SSH 目标没有界面入口，不写成可配置功能。

正文不解释内部调度、通信协议或故障保护机制，只保留能帮助用户选择设备、判断离线原因和恢复运行的信息。
