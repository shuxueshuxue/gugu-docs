# troubleshooting

本页只收录咕咕已经明确识别并向用户显示的故障或异常状态。每一项依次说明用户看到的提示、提示所代表的状态，以及产品已经提供的处理动作。界面文案以产品源码中的用户可见字符串为准；只有产品 spec 和源码都无法证明的通用排查建议不进入本页。

覆盖范围包括 agent 创建失败与长时间启动、单轮回复失败、引擎错误的聊天记录、运行状态自动核实、旧主机徽标、邮箱验证码、登录态丢失，以及外部本地引擎缺失。正文不得把内部错误、实现术语或未接入的设置写成用户功能。

正文每句话只承担一个意思。正文不使用破折号。需要枚举的内容使用列表，不用顿号或句中冒号压进行文。中文默认省略「你」。只有需要区分读者与其他人时才保留。界面文案原样引用。各故障统一按「会看到什么」「表示什么」「可以怎么做」组织。正文使用普通产品用语，不另造名称。
