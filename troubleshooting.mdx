title: "遇到问题"
description: "咕咕在创建、回复、状态、登录和引擎出问题时都会给出提示，这一页讲怎么读它们。"
---

## Agent 创建失败

**会看到什么**：

咕咕会显示「`Agent 名称` 创建失败：`原因`」。失败原因可能是以下三种：

- 「设备已离线，Agent 未能启动」
- 「设备长时间未响应，Agent 未能启动」
- 「设备启动 Agent 时出错，未能完成创建」

创建面板还会提示「上次创建未完成：`原因`。配置已保留，点击「创建」重试。」

**表示什么**：创建没有完成。咕咕不会改用其他引擎。一次可重试的创建失败不会自动删除相关内容。咕咕会保留以下内容，等待重试或放弃：

- 同一个 agent
- 单聊
- 创建记录

**可以怎么做**：检查所选设备和引擎。回到保留了原配置的创建面板，再点「创建」。

## Agent 长时间停在「启动中」

**会看到什么**：创建后先出现「Agent 正在上线：`名称`」。等待时间较长时，本地 agent 会提示「`名称` 仍在启动（可能在下载运行时）」。云端 agent 会提示「`名称` 仍在启动（云端处理较慢）」。

**表示什么**：这条提示还不代表创建失败。等待时间已经结束，但咕咕还没有收到成功或失败的最终结果。创建任务可能仍在等待或执行，咕咕会继续观察。本机准备 Claude 或 Codex 运行时的时候，右下角还会显示准备进度。

**可以怎么做**：等待后续结果。如果右下角显示「Claude 运行时下载失败」或「Codex 运行时下载失败」，点卡片里的「重试」。如果随后出现创建失败提示，按上一节重试创建。

## 某一轮回复失败

**会看到什么**：输入框上方原来显示运行状态的位置会换成失败提示。提示会显示 agent 名称和以下一种失败原因：

- 「Agent 长时间未响应，本次回复未完成」
- 「设备连接中断，本次回复未完成」
- 「Agent 本次回复出错，未能完成」

提示旁边有「重试」和关闭按钮。

**表示什么**：当前会话或话题里的这一轮没有完成。失败提示只属于发生错误的会话或话题。新一轮开始后，旧的失败提示会消失。

**可以怎么做**：点「重试」会重新提交原来那一轮。按钮提交期间显示「重试中…」。重试没有提交成功时，失败提示会保留，可以再次操作。关闭按钮只收起提示。

## 聊天记录里出现引擎错误

**会看到什么**：聊天记录里出现一条系统提示。「Agent 本回合未能回复，请稍后重试。」

**表示什么**：引擎遇到了错误，例如：

- 鉴权
- 配额
- 网络

系统提示会留在聊天记录里。同一轮重新提交不会重复添加相同提示。内部错误详情不会显示在这里。

**可以怎么做**：处理所选引擎的问题。需要处理的方面可能是：

- 登录状态
- 配额
- 网络连接

处理后，再点这一轮失败提示上的「重试」。

## 「运行中」没有及时消失

**会看到什么**：agent 已经结束工作，界面仍显示「运行中」。

**表示什么**：咕咕可能没有收到这一轮结束的事件。「运行中」显示满 90 秒后，咕咕会向云端重新读取 agent 状态。云端确认 agent 空闲后，界面会清除「运行中」。如果这次读取无法判断，咕咕每 30 秒复查一次，最多复查 10 次。

**可以怎么做**：先等待 90 秒后的自动核实，不需要重建 agent。如果之后出现回复失败提示，使用该提示的「重试」。

## Agent 旁边显示「主机旧」

**会看到什么**：agent 旁边出现带警告图标的「主机旧」徽标。完整提示是「Agent 所在主机的咕咕版本偏旧，缺少部分上报能力（如最近活动）；不影响当前对话，建议升级该主机（与你的账号/咕咕号无关）」。

**表示什么**：agent 所在机器的咕咕版本缺少部分状态上报能力，当前对话仍可使用。这个徽标与账号或咕咕号无关。

**可以怎么做**：升级 agent 所在机器上的咕咕。需要升级的是运行 agent 的那台机器，不一定是当前使用的设备。

## 收不到登录验证码

**会看到什么**：提交邮箱后，登录页显示「验证码已发送至 `邮箱`，请查收邮件」，并显示 60 秒倒计时的「重新发送」。发送请求失败时会显示「验证码发送失败，请稍后重试」。

**表示什么**：发送成功后，咕咕已经接受发码请求，并开始重发倒计时。登录使用 6 位验证码。

**可以怎么做**：先核对页面上显示的邮箱。邮箱不对时，点「换邮箱」。邮箱正确时，等倒计时结束，再点「重新发送」。

## 突然回到登录页

**会看到什么**：咕咕回到邮箱登录页。如果本机 agent 恰好有尚未发出的回复，登录页还会显示「登录已失效，期间 agent 有 `数量` 条回复未发出，重新登录后自动补投。」

**表示什么**：主动点「退出登录」会正常回到登录页。没有主动退出却回到登录页，表示原登录状态已经失效。咕咕会区分这两种情况。主动退出时不会把它写成「登录已失效」。

**可以怎么做**：用邮箱验证码重新登录。有待发送回复时，重新登录后咕咕会自动补投。

## 本地引擎没有安装

**会看到什么**：创建对应的本地 agent 时会失败，并提示「本地引擎运行时缺失：找不到可执行的 `命令`。请确认该运行时已安装并在 PATH 中，或改用云端 agent。」各引擎需要找到的命令如下：

| 引擎 | 命令 |
|---|---|
| Gemini CLI | `gemini` |
| OpenCode | `opencode` |
| Hermes | `hermes` |
| OpenClaw | `openclaw` |

**表示什么**：所选机器无法找到该引擎的本地命令。咕咕不会改用 Claude 或其他引擎继续创建。

**可以怎么做**：在 agent 所在机器上安装所选引擎，并确保系统能从 PATH 找到表中的命令。然后重试创建。也可以改选云端 agent。
