跟 agent 说话和跟人说话走的是同一套会话界面。

## 输入区

回车发送，Shift + 回车换行。没发出去的内容留成草稿，切走再回来还在。

- **附件**。粘贴或选择图片和文件。多个附件是一件一件提交的，中间失败会停下来报错，已经发出去的不会再回到草稿里重复发一遍。
- **语音**。按住录，发出去是一条语音消息。
- **斜杠命令**。输入 `/` 唤出命令面板，常用动作在里面。
- **转发**。把一条消息转发到别的会话，选目标会话即可。

## 话题

在一条消息上开话题，之后在话题视图里发的消息都归在这条话题下面，不进主时间线。一件事的来回集中在一处，不跟群里其他消息混在一起。

## 悄悄话

在群里点某个成员的头像，从资料卡进悄悄话模式，这时候发的消息只有你和对方看得见。消息气泡上会标出来。发出去的那边显示「悄悄话给某某 · 仅你与对方可见」，收到的那边显示「悄悄话 · 仅你可见」。

悄悄话对 agent 是硬触发，不管它的倾听模式是哪一档都会应。

## agent 回复时

**状态提示在输入框上方**，是一条浮动的横条。它显示 agent 在想，写作「思考中」，或者显示它最新调的那个工具的动作名。消息列表里不会插入运行中的占位行。在话题视图里，提示出现在这一段的末尾。

**回复是一边生成一边显示的**，但存进聊天记录的那条才算数。这一轮结束时，生成中的内容让位给正式消息，不会留下两条。

出错分三种情况。

- 一轮回复失败时，原来放状态提示的位置换成一条失败提示，旁边有重试按钮。重试会把这一轮完整重新执行一次。
- 引擎那边的鉴权、配额、网络这类错误，会作为一条系统提示留在聊天记录里。失败提示刷新就没了，聊天记录才留得住。
- 如果一轮结束了，agent 却什么也没做，只写了段文本，那段文本也会显示出来。不会出现发了消息却一声不吭的情况。

## 通知

哪些事件要弹系统通知，在设置的通知偏好里改。当前会话开着而且应用在前台时不弹，因为已经看见了。
