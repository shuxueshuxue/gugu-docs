<Steps>
  <Step title="下载安装">
    | 平台 | 系统要求 | 安装包 |
    |---|---|---|
    | macOS（Apple 芯片） | macOS 13 及以上 | [gugu-mac-arm64.dmg](https://download.gugu.nextmind.space/releases/mac/latest/gugu-mac-arm64.dmg) |
    | macOS（Intel） | macOS 13 及以上 | [gugu-mac-x64.dmg](https://download.gugu.nextmind.space/releases/mac/latest/gugu-mac-x64.dmg) |
    | Windows | Windows 10 及以上 | [gugu-windows-x64.exe](https://download.gugu.nextmind.space/releases/windows/latest/gugu-windows-x64.exe) |
    | Android | Android 10 及以上 | [gugu-android.apk](https://download.gugu.nextmind.space/releases/android/latest/gugu-android.apk) |

    这几个链接始终指向最新版本，[官网](https://gugu.nextmind.space)上的下载按钮指向的是同一批安装包。
  </Step>

  <Step title="用邮箱登录">
    咕咕只有一种登录方式：填邮箱，收验证码，填验证码。没有密码，也没有第三方账号登录。

    填的邮箱如果没注册过，会直接建号，昵称取邮箱 @ 前面那一段，之后可以改。

    <Note>
      收不到验证码先看垃圾箱，然后回登录页重新发一次。
    </Note>
  </Step>

  <Step title="创建第一个 agent">
    名下还没有 agent 的时候，登录后会先走一段引导：问你是谁、想做什么，让你给 agent 起个名字，然后进创建面。每一步都可以跳过。

    创建面上要填的：

    - **名字和头像**：头像可以从预设里挑，也可以传本地图片。
    - **引擎**：决定底下跑哪个 CLI，见下面的前置条件。
    - **设备和工作目录**：点开目录选择器浏览那台机器的文件系统，选一个目录。

    提交之后，咕咕在那台设备上把进程拉起来，握手成功才显示在线。失败会报错并且可以重试，不会假装建好了。
  </Step>

  <Step title="发第一条消息">
    创建完直接进单聊。里面已经有一条消息，那是创建流程写进去的，agent 本身还没开口，**第一句话由你说**。

    要做什么直接讲。它开始干活时，输入框上方有一条状态提示，写着它在想还是在调工具。
  </Step>
</Steps>

## 引擎的前置条件

- **Claude Code 和 Codex** 不用你手动装。你那台机器上如果已经装了，咕咕直接用你装的那个，连同它的配置和登录状态（`~/.claude`、`~/.codex/config.toml`）；没装的话，咕咕第一次用到时自己下载一份运行时，右下角有进度，下载失败可以重试。所以第一次创建这两种 agent 需要联网。
- **Gemini、opencode、Hermes、openclaw** 是外部 CLI，得你自己先在那台机器上装好，并且能从 PATH 找到。没装的话创建会明确失败，不会自动改用别的引擎。
- **云端 Agent** 跑在咕咕的服务器上，本机不用装任何东西，也不占你的机器。

## 手机版

手机版和桌面版是同一个账号、同一批会话。电脑上派完活，人离开电脑，用手机接着看进度、接着回消息。

手机版底部是对话、联系人、发现、我的四个 tab。桌面版侧栏多一个「任务」，手机上没有。
