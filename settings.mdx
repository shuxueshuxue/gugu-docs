---

桌面版的设置在侧栏头像菜单里，不占顶层导航的位置。先点侧栏顶部的头像，再点「设置」。设置面板随即显示为弹窗。

头像菜单里的「额度」可以直接进入额度页。「退出登录」可以直接退出当前账号。

## 账户资料与咕咕号

在「账户」页可以修改以下资料：

- 名称
- 头像
- 简介

邮箱只供查看，不能在这里修改。改完名称或简介后，点「保存」。

点头像可以上传以下格式的新图片：

- JPG
- PNG
- WebP

咕咕号显示在设置面板左侧的个人资料卡里，位于名称下方。点号码旁的复制按钮即可复制。咕咕号还没分配时，这里会显示「咕咕号未分配」。

「账户」页底部也有「退出登录」按钮。

## 模型

「模型」页目前是说明页。页面显示咕咕服务器提供 20 个模型，无需填写模型服务商密钥。

这项说明不改变本地 agent 的模型配置。本地 agent 仍使用这台机器上相应 CLI 自己的配置，咕咕默认不替它选择模型，详见 [Agent](/agents#设备和引擎)。

<Note>
  「添加」目前只会显示“自带模型服务商 API Key 即将支持”的提示，不能添加或保存模型服务。页面下方列出的其他服务商也还不能配置。
</Note>

## 额度与充值

「额度」页显示当前积分余额。每天登录时，咕咕会自动赠送积分。赠送数额以实际到账为准。

点「充值」后可以选择：

- 充值金额：
  - 6 元
  - 30 元
  - 100 元
  - 298 元
- 支付方式：支付宝或微信支付
- 兑换比例：1 元兑 100 积分

确认金额和支付方式后点「去支付」。咕咕会转到支付页面。支付完成后，再次进入设置即可查看入账后的余额。创建订单失败时，额度页会直接显示错误信息。

## 通知

通知开关在「通用」页。当前只有一个「开启通知」总开关，默认开启。它控制以下系统通知：

- 会话收到新消息
- agent 开始工作或上线
- agent 启动失败
- agent 回复失败

咕咕正在前台时不会弹这些系统通知。关闭开关后也不会再弹。这个偏好保存在当前设备上。

## 版本与更新

「关于」页显示当前安装版本。点「检查更新」可以立即检查。新版本下载完成后，按钮会变成「有新版本，重启安装」。点它即可重启并安装更新。
