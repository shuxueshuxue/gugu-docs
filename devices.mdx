设备决定 agent 在哪里运行。选择自己的电脑后，agent 就在那台电脑上使用本地引擎和文件。选择咕咕云后，云端 Agent 就在咕咕提供的环境中运行。

## 添加一台电脑

在 macOS 或 Windows 电脑上安装咕咕桌面版，再登录账号。这台电脑会自动登记为一台设备，不需要手动添加。

登记后，在 **设置 → 设备** 中可以看到它。Android 手机可以查看会话和发消息，但不能作为 agent 的运行设备。

<Note>
  创建本地 agent 时，只能选择当前在线的电脑。离线设备仍会列出，但不能选中。没有在线电脑时，可以启动那台电脑上的咕咕并确认账号仍处于登录状态，或者改用云端 Agent。
</Note>

## 设备列表

进入 **设置 → 设备**。每台电脑会显示：

- **设备名**：默认按设备生成，可以改成便于辨认的名字。
- **主机名**：电脑在系统中的名称。
- **在线状态**：
  - 绿色状态点表示在线。
  - 离线设备会显示今天内离线或多少天未上线。
- **本机**：标出当前正在使用的这台电脑。
- **咕咕版本**：
  - 显示该设备上的版本。
  - 无法取得时显示「版本未知」。

本机会排在最前面，随后是其他在线设备和离线设备。

设备可以改名。正在使用的本机不能删除。删除其他设备前，咕咕会检查上面是否还有 agent。

有 agent 时，必须确认把这些 agent 一并永久删除。没有 agent 的设备可以直接删除。以后在那台电脑上重新登录时，设备会再次自动登记。

## 在线与离线

咕咕桌面版运行并保持登录时，电脑大约每 30 秒报告一次在线状态。距离最后一次报告超过约 2 分钟后，其他客户端会把这台设备判为离线。

设备离线后，上面的 agent 也显示离线，且不能再用这台设备创建 agent。已经发出的任务会保留，等设备恢复连接后再处理。

正常退出咕咕时，应用会停止它启动的本地 agent 进程，并报告这些 agent 已离线。电脑断电或断网时来不及报告，状态通常会在最后一次在线报告超过约 2 分钟后变成离线。

要恢复运行，请启动那台电脑上的咕咕，保持网络连接，并确认使用的是原账号。

## 本地设备与咕咕云

### 自己的电脑

- 可运行的 agent：
  - Claude Code
  - Codex
  - Gemini
  - opencode
  - Hermes
  - openclaw
- 需要保持在线：
  - 这台电脑
  - 网络
  - 咕咕桌面版
- 适合需要使用这台电脑上以下内容的任务：
  - 代码
  - 数据
  - CLI 配置
  - 登录状态

### 咕咕云

- 可运行的 agent：
  - 云端 Agent
- 需要保持在线：不依赖自己的电脑在线
- 适合的任务：希望电脑关机后仍可继续的任务

创建 agent 时，「运行设备」列表会同时显示咕咕云和自己的电脑。咕咕云标为「常在线 · 咕咕提供」，只支持云端 Agent。本地引擎只能选择在线的自有设备。

## 文件所在的设备

本地 agent 使用运行设备的文件系统。文件只在实验室电脑上，就应选择实验室电脑。文件只在个人电脑上，就应选择个人电脑。当前用来查看咕咕的设备，不会改变 agent 实际使用哪台电脑的文件。

当前创建界面只提供运行设备选择，不提供工作目录选择。选择一段本机会话继续时，如果来源和目标使用同一种引擎且都在本机，工作目录会随原会话继续使用。

咕咕云不在自己的电脑上运行。任务需要读取只存在于某台电脑上的文件时，应选择那台电脑作为运行设备。

## 与设备有关的设置

**设置 → 设备** 当前提供设备改名和删除。

桌面版的 **设置 → 通用 → 运行时** 还可以指定 Claude Code 可执行文件。这个路径只在当前电脑生效，不随账号同步。留空时使用内置版本。

当前界面不提供 SSH 目标设置。
