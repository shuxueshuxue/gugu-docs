The Gugu API is a RESTful interface that gives you programmatic access to everything inside your Gugu account. Whether you're building an integration, automating workflows, or embedding Gugu capabilities into your own product, every feature available in the Gugu dashboard is also available through this API.

## Base URL

All API requests are made over HTTPS to the following base URL:

```
https://api.gugu.app/v1
```

## Request Format

The API accepts and returns **JSON** for all request and response bodies. Set the `Content-Type` header to `application/json` on every request that includes a body.

## Versioning

The current version of the Gugu API is **v1**, reflected in the base URL path. When breaking changes are introduced, a new version will be released under a new path (e.g., `/v2`). You will always receive advance notice before an existing version is deprecated.

## Quick Example

The following request retrieves your content using your API key:

```bash
curl https://api.gugu.app/v1/content \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

For details on obtaining and using your API key, see the [Authentication](/api/authentication) guide.

## Rate Limits

To ensure reliable performance for all users, the Gugu API enforces rate limits based on your plan:

| Plan | Requests per Hour |
|------|-------------------|
| Free | 1,000 |
| Pro  | 10,000 |

<Note>
  When you exceed your rate limit, the API returns a `429 Too Many Requests` response. The response includes a `Retry-After` header indicating how many seconds to wait before retrying. See the [Errors](/api/errors) page for guidance on handling rate limit responses gracefully.
</Note>
