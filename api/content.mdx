The Content API lets you build and manage the content items that live in your Gugu workspace. Whether you're populating a knowledge base, syncing posts from an external system, or building an editorial pipeline, this API gives you the full range of CRUD operations. All endpoints require a valid Bearer token in the `Authorization` header.

---

## List content items

Returns a paginated list of content items in your workspace. You can filter by tag or collection and control the sort order.

```text
GET /v1/content
```

### Query parameters

<ParamField query="page" type="integer">
  The page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Number of items to return per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="tag" type="string">
  Filter results to items that include this tag.
</ParamField>

<ParamField query="collection_id" type="string">
  Filter results to items that belong to this collection.
</ParamField>

<ParamField query="sort" type="string">
  Field to sort results by. Accepted values: `created_at`, `updated_at`. Defaults to `created_at`.
</ParamField>

<ParamField query="order" type="string">
  Sort direction. Accepted values: `asc`, `desc`. Defaults to `desc`.
</ParamField>

### curl example

```bash
curl "https://api.gugu.app/v1/content?page=1&per_page=25&tag=announcement&sort=updated_at&order=desc" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response fields

<ResponseField name="data" type="array">
  An array of content objects. See [The content object](#the-content-object) for field descriptions.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for the current result set.

  <Expandable title="meta fields">
    <ResponseField name="meta.total" type="integer">
      Total number of content items matching the query.
    </ResponseField>

    <ResponseField name="meta.page" type="integer">
      The current page number.
    </ResponseField>

    <ResponseField name="meta.per_page" type="integer">
      The number of items returned per page.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example response

```json
{
  "data": [
    {
      "id": "cnt_01abc",
      "title": "Q3 Product Update",
      "body": "Here's what we shipped this quarter...",
      "tags": ["announcement", "product"],
      "collection_id": "col_99xyz",
      "created_at": "2024-06-01T09:00:00Z",
      "updated_at": "2024-06-05T14:30:00Z",
      "author": {
        "id": "usr_01hxyz",
        "name": "Ada Lovelace"
      }
    }
  ],
  "meta": {
    "total": 84,
    "page": 1,
    "per_page": 25
  }
}
```

### Error responses

```json
{
  "error": {
    "code": "unauthorized",
    "message": "Missing or invalid Bearer token.",
    "status": 401
  }
}
```

## Create a content item

Creates a new content item in your workspace and returns the full item object.

```text
POST /v1/content
```

### Body parameters

<ParamField body="title" type="string" required>
  The title of the content item.
</ParamField>

<ParamField body="body" type="string">
  The main body text of the content item. Supports Markdown.
</ParamField>

<ParamField body="tags" type="array">
  An array of string tags to associate with the item (e.g. `["release", "v2"]`).
</ParamField>

<ParamField body="collection_id" type="string">
  The ID of the collection to place this item in. If omitted, the item is created outside any collection.
</ParamField>

### curl example

```bash
curl -X POST https://api.gugu.app/v1/content \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Q3 Product Update",
    "body": "Here'\''s what we shipped this quarter...",
    "tags": ["announcement", "product"],
    "collection_id": "col_99xyz"
  }'
```

### Response fields

Returns the newly created content object.

<ResponseField name="id" type="string">
  Unique identifier for the content item.
</ResponseField>

<ResponseField name="title" type="string">
  The title of the content item.
</ResponseField>

<ResponseField name="body" type="string">
  The full body text of the content item, in Markdown.
</ResponseField>

<ResponseField name="tags" type="array">
  An array of string tags associated with the item.
</ResponseField>

<ResponseField name="collection_id" type="string | null">
  The ID of the collection this item belongs to, or `null` if uncategorized.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the item was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update to the item.
</ResponseField>

<ResponseField name="author" type="object">
  The user who created the content item.

  <Expandable title="author fields">
    <ResponseField name="author.id" type="string">
      Unique identifier of the author.
    </ResponseField>

    <ResponseField name="author.name" type="string">
      Display name of the author.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example response

```json
{
  "id": "cnt_01abc",
  "title": "Q3 Product Update",
  "body": "Here's what we shipped this quarter...",
  "tags": ["announcement", "product"],
  "collection_id": "col_99xyz",
  "created_at": "2024-06-01T09:00:00Z",
  "updated_at": "2024-06-01T09:00:00Z",
  "author": {
    "id": "usr_01hxyz",
    "name": "Ada Lovelace"
  }
}
```

### Error responses

```json
{
  "error": {
    "code": "validation_error",
    "message": "title is required.",
    "status": 400
  }
}
```

## Update a content item

Updates one or more fields on an existing content item. Only the fields you include in the request body are changed.

```text
PUT /v1/content/:id
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the content item to update.
</ParamField>

### Body parameters

<ParamField body="title" type="string">
  Updated title for the content item.
</ParamField>

<ParamField body="body" type="string">
  Updated body text. Supports Markdown.
</ParamField>

<ParamField body="tags" type="array">
  Replacement array of tags. This **replaces** the existing tag list entirely — to add a single tag, send the full desired array.
</ParamField>

<ParamField body="collection_id" type="string">
  Move the item to a different collection by supplying the new collection's ID. Send `null` to remove it from any collection.
</ParamField>

### curl example

```bash
curl -X PUT https://api.gugu.app/v1/content/cnt_01abc \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Q3 Product Update (Revised)",
    "tags": ["announcement", "product", "revised"]
  }'
```

### Response fields

Returns the updated content object.

<ResponseField name="id" type="string">
  Unique identifier for the content item.
</ResponseField>

<ResponseField name="title" type="string">
  The updated title of the content item.
</ResponseField>

<ResponseField name="body" type="string">
  The full body text of the content item, in Markdown.
</ResponseField>

<ResponseField name="tags" type="array">
  The updated array of string tags associated with the item.
</ResponseField>

<ResponseField name="collection_id" type="string | null">
  The ID of the collection this item belongs to, or `null` if uncategorized.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the item was originally created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of this update.
</ResponseField>

<ResponseField name="author" type="object">
  The user who created the content item.

  <Expandable title="author fields">
    <ResponseField name="author.id" type="string">
      Unique identifier of the author.
    </ResponseField>

    <ResponseField name="author.name" type="string">
      Display name of the author.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example response

```json
{
  "id": "cnt_01abc",
  "title": "Q3 Product Update (Revised)",
  "body": "Here's what we shipped this quarter...",
  "tags": ["announcement", "product", "revised"],
  "collection_id": "col_99xyz",
  "created_at": "2024-06-01T09:00:00Z",
  "updated_at": "2024-06-10T11:00:00Z",
  "author": {
    "id": "usr_01hxyz",
    "name": "Ada Lovelace"
  }
}
```

### Error responses

```json
{
  "error": {
    "code": "not_found",
    "message": "No content item found with the given ID.",
    "status": 404
  }
}
```

## Delete a content item

Permanently deletes a content item. This action cannot be undone.

```text
DELETE /v1/content/:id
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the content item to delete.
</ParamField>

### curl example

```bash
curl -X DELETE https://api.gugu.app/v1/content/cnt_01abc \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

Returns `204 No Content` on success with an empty response body.

### Error responses

```json
{
  "error": {
    "code": "not_found",
    "message": "No content item found with the given ID.",
    "status": 404
  }
}
```
