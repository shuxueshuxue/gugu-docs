---

The Users API gives you full control over your Gugu account profile and API credentials. Use it to read or update your display name, avatar, and bio, and to create or revoke the API keys that authenticate your programmatic requests. All endpoints require a valid Bearer token in the `Authorization` header.

---

## Get current user

Retrieves the profile of the currently authenticated user.

```text
GET /v1/users/me
```

### curl example

```bash
curl https://api.gugu.app/v1/users/me \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the user.
</ResponseField>

<ResponseField name="email" type="string">
  The email address associated with the account.
</ResponseField>

<ResponseField name="name" type="string">
  The user's display name.
</ResponseField>

<ResponseField name="avatar_url" type="string">
  Publicly accessible URL pointing to the user's avatar image.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the account was created.
</ResponseField>

<ResponseField name="plan" type="string">
  The user's current subscription plan (e.g. `free`, `pro`, `enterprise`).
</ResponseField>

### Example response

```json
{
  "id": "usr_01hxyz",
  "email": "ada@example.com",
  "name": "Ada Lovelace",
  "avatar_url": "https://cdn.gugu.app/avatars/ada.png",
  "created_at": "2024-01-15T09:00:00Z",
  "plan": "pro"
}
```

### Error responses

```json
{
  "error": {
    "code": "unauthorized",
    "message": "Missing or invalid Bearer token.",
    "status": 401
  }
}
```

## Update current user

Updates the profile fields of the currently authenticated user. Only the fields you include in the request body are changed; omitted fields are left untouched.

```text
PUT /v1/users/me
```

### Body parameters

<ParamField body="name" type="string">
  New display name for the user.
</ParamField>

<ParamField body="avatar_url" type="string">
  URL of the new avatar image. Must be a publicly accessible HTTPS URL.
</ParamField>

<ParamField body="bio" type="string">
  Short biography or description displayed on the user's public profile.
</ParamField>

### curl example

```bash
curl -X PUT https://api.gugu.app/v1/users/me \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Ada Lovelace",
    "avatar_url": "https://cdn.gugu.app/avatars/ada-new.png",
    "bio": "Pioneer of computing and avid Gugu user."
  }'
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the user.
</ResponseField>

<ResponseField name="email" type="string">
  The email address associated with the account.
</ResponseField>

<ResponseField name="name" type="string">
  The updated display name.
</ResponseField>

<ResponseField name="avatar_url" type="string">
  The updated avatar URL.
</ResponseField>

<ResponseField name="bio" type="string">
  The updated biography.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the account was created.
</ResponseField>

<ResponseField name="plan" type="string">
  The user's current subscription plan.
</ResponseField>

### Example response

```json
{
  "id": "usr_01hxyz",
  "email": "ada@example.com",
  "name": "Ada Lovelace",
  "avatar_url": "https://cdn.gugu.app/avatars/ada-new.png",
  "bio": "Pioneer of computing and avid Gugu user.",
  "created_at": "2024-01-15T09:00:00Z",
  "plan": "pro"
}
```

### Error responses

```json
{
  "error": {
    "code": "validation_error",
    "message": "avatar_url must be a valid HTTPS URL.",
    "status": 400
  }
}
```

## List API keys

Returns all API keys associated with your account. For security, the full key value is never returned by this endpoint — only the prefix and metadata.

```text
GET /v1/users/me/api-keys
```

### curl example

```bash
curl https://api.gugu.app/v1/users/me/api-keys \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response fields

The response is an array of API key objects.

<ResponseField name="id" type="string">
  Unique identifier for the API key.
</ResponseField>

<ResponseField name="name" type="string">
  The human-readable label you assigned to this key.
</ResponseField>

<ResponseField name="prefix" type="string">
  The first few characters of the key, useful for identification (e.g. `gugu_live_abc1…`).
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the key was created.
</ResponseField>

<ResponseField name="last_used_at" type="string | null">
  ISO 8601 timestamp of the most recent request authenticated with this key. `null` if the key has never been used.
</ResponseField>

<ResponseField name="scopes" type="array">
  List of permission scopes granted to this key (e.g. `["read", "write"]`).
</ResponseField>

### Example response

```json
[
  {
    "id": "key_01abc",
    "name": "CI Pipeline",
    "prefix": "gugu_live_k8m2",
    "created_at": "2024-03-10T12:00:00Z",
    "last_used_at": "2024-06-01T08:45:00Z",
    "scopes": ["read", "write"]
  },
  {
    "id": "key_02def",
    "name": "Read-only Integration",
    "prefix": "gugu_live_r3n9",
    "created_at": "2024-05-22T16:30:00Z",
    "last_used_at": null,
    "scopes": ["read"]
  }
]
```

### Error responses

```json
{
  "error": {
    "code": "unauthorized",
    "message": "Missing or invalid Bearer token.",
    "status": 401
  }
}
```

## Create an API key

Generates a new API key for your account. You can scope the key to limit what operations it can perform.

```text
POST /v1/users/me/api-keys
```

<Warning>
  The full API key value is returned **only once**, at the moment of creation. Gugu does not store the raw key and cannot show it to you again. Copy and store it securely immediately — if you lose it, you must revoke the key and create a new one.
</Warning>

### Body parameters

<ParamField body="name" type="string" required>
  A descriptive label for the key so you can identify it later (e.g. `"CI Pipeline"` or `"Mobile App"`).
</ParamField>

<ParamField body="scopes" type="array">
  An array of permission scopes to grant the key. Accepted values are `"read"` and `"write"`. Defaults to `["read"]` if omitted.
</ParamField>

### curl example

```bash
curl -X POST https://api.gugu.app/v1/users/me/api-keys \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "CI Pipeline",
    "scopes": ["read", "write"]
  }'
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the newly created API key.
</ResponseField>

<ResponseField name="name" type="string">
  The label assigned to the key.
</ResponseField>

<ResponseField name="key" type="string">
  The full API key value. **Store this immediately** — it will not be shown again.
</ResponseField>

<ResponseField name="prefix" type="string">
  The first few characters of the key for future identification.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the key was created.
</ResponseField>

<ResponseField name="scopes" type="array">
  The permission scopes granted to this key.
</ResponseField>

### Example response

```json
{
  "id": "key_03ghi",
  "name": "CI Pipeline",
  "key": "gugu_live_k8m2xxxxxxxxxxxxxxxxxxxxxx",
  "prefix": "gugu_live_k8m2",
  "created_at": "2024-06-15T10:00:00Z",
  "scopes": ["read", "write"]
}
```

### Error responses

```json
{
  "error": {
    "code": "validation_error",
    "message": "name is required.",
    "status": 400
  }
}
```

## Revoke an API key

Permanently revokes an API key. Any requests authenticated with the revoked key will immediately begin receiving `401 Unauthorized` responses. This action cannot be undone.

```text
DELETE /v1/users/me/api-keys/:id
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the API key to revoke.
</ParamField>

### curl example

```bash
curl -X DELETE https://api.gugu.app/v1/users/me/api-keys/key_03ghi \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

Returns `204 No Content` on success with an empty response body.

### Error responses

```json
{
  "error": {
    "code": "not_found",
    "message": "No API key found with the given ID.",
    "status": 404
  }
}
```

<Tip>
  If you suspect a key has been compromised, revoke it immediately and audit your recent API activity in the Gugu dashboard before creating a replacement.
</Tip>
