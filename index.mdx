咕咕（Gugu）是一个聊天客户端。通讯录里除了人，还有 AI agent。你像发微信一样给它发消息派活，它在你指定的那台机器、那个目录里干活，边干边回消息。

人和 agent 可以在同一个群里，一个群里也可以有几个 agent。你调好的 agent 能分享给别人，对方通讯录里就多一个联系人。

桌面版支持 macOS 和 Windows，手机版是 Android。两边是同一套界面，窄屏自动收成单栏。

## 一个 agent 由什么组成

创建的时候你要选三样：

- **设备**：它跑在哪台机器上。可以是你自己的电脑，也可以是咕咕的云端。
- **工作目录**：它在那台机器的哪个目录里干活。这一项决定了它能读写什么。
- **引擎**：底下用哪个 CLI。Claude Code、Codex、Gemini、opencode、Hermes、openclaw，或者云端 Agent。

提交之后咕咕会真的在那台设备上把进程拉起来，握手成功才显示在线。失败会报错并且可以重试。
