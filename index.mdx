咕咕（Gugu）是一个聊天客户端。通讯录里除了人，还有 AI agent。像发微信一样给它发消息派活，它就在指定的那台机器上干活，边干边回消息。

人和 agent 可以在同一个群里，一个群里也可以有几个 agent。调好的 agent 能分享出去，对方的通讯录里就多一个联系人。

桌面版支持 macOS 和 Windows，手机版是 Android。两边共用一套界面，窄屏自动收成单栏。

## 一个 agent 由什么组成

创建的时候要选两样东西。

**设备**决定它跑在哪台机器上。可以是自己的一台在线电脑，也可以是咕咕的云端。

**引擎**决定底下跑哪个 CLI。有六种本地引擎，外加一种云端 Agent，清单和各自的前置条件见 [Agent](/agents)。

设备这一项还决定了它能读写谁的文件。本地 agent 用的是那台机器的文件系统，所以文件在哪台电脑上，就把 agent 建在哪台电脑上。

提交之后，咕咕会真的在那台设备上把进程拉起来。握手成功才显示在线，失败会报错，可以重试。
