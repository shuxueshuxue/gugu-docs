Gugu takes the security of your account seriously. Every sign-in is encrypted in transit, sessions are scoped and revocable, and you have full control over how both humans and machines authenticate with your workspace. This page walks you through all the ways to prove your identity and protect your data.

## Sign-In Methods

Gugu supports multiple ways to sign in so you can choose whatever fits your workflow.

### Email and Password

Sign in at [app.gugu.app/login](https://app.gugu.app/login) with the email address and password you used when you created your account.

<Steps>
  <Step title="Go to the login page">
    Navigate to [app.gugu.app/login](https://app.gugu.app/login) in your browser.
  </Step>
  <Step title="Enter your credentials">
    Type your email address and password into the respective fields.
  </Step>
  <Step title="Click Sign In">
    Press **Sign In** or hit <kbd>Enter</kbd>. If two-factor authentication is enabled, you'll be prompted for a verification code next.
  </Step>
</Steps>

If you forget your password, click **Forgot password?** on the login page and Gugu will send a reset link to your registered email address.

### Social Login

You can sign in with an existing Google or GitHub account — no separate password required.

<Steps>
  <Step title="Choose a provider">
    On the login page, click **Continue with Google** or **Continue with GitHub**.
  </Step>
  <Step title="Authorize Gugu">
    You'll be redirected to the provider's authorization screen. Review the requested permissions and click **Authorize** (or **Allow**).
  </Step>
  <Step title="Return to Gugu">
    After authorization, you'll land back in your Gugu workspace automatically. On first sign-in, Gugu creates your account using the name and avatar from your provider profile.
  </Step>
</Steps>

<Info>
  You can link multiple sign-in methods to the same account from **Settings → Security → Connected Accounts**. This lets you sign in with Google or GitHub even if you originally registered with email and password.
</Info>

## Two-Factor Authentication (2FA)

Two-factor authentication adds a second layer of protection by requiring a one-time code in addition to your password. Gugu supports any TOTP-compatible authenticator app (such as Google Authenticator, Authy, or 1Password).

<Steps>
  <Step title="Open Security settings">
    Click your avatar in the top-right corner, select **Settings**, then navigate to the **Security** tab.
  </Step>
  <Step title="Enable 2FA">
    Under **Two-Factor Authentication**, click **Enable**. Gugu displays a QR code.
  </Step>
  <Step title="Scan the QR code">
    Open your authenticator app, tap **Add account** (or the **+** icon), and scan the QR code.
  </Step>
  <Step title="Enter the verification code">
    Type the six-digit code generated by your app into the confirmation field and click **Verify**.
  </Step>
  <Step title="Save your recovery codes">
    Gugu generates a set of single-use recovery codes. **Store these somewhere safe** — they're the only way to regain access if you lose your authenticator device.
  </Step>
</Steps>

Once 2FA is active, every sign-in will ask for a code after your password. To disable 2FA, return to **Settings → Security** and click **Disable** — you'll need to enter a valid code to confirm.

## API Keys

API keys let your scripts, integrations, and third-party tools authenticate with Gugu's REST API on your behalf. Each key is tied to your account and inherits your permissions. For the full API reference, see the [API Authentication docs](/api/authentication).

### Generating an API Key

<Steps>
  <Step title="Navigate to API Keys">
    Go to **Settings → API Keys**.
  </Step>
  <Step title="Click Generate New Key">
    Click **Generate New Key**, give it a descriptive name (e.g., `CI pipeline`, `Zapier integration`), and optionally set an expiration date.
  </Step>
  <Step title="Copy your key">
    Your new key appears **once**. Copy it and store it securely — Gugu never shows the full key again after you close this dialog.
  </Step>
</Steps>

### Using Your API Key

Pass the key in the `Authorization` header of every API request using the `Bearer` scheme:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.gugu.app/v1/content
```

You can also set it as an environment variable to avoid hardcoding it in scripts:

```bash
export GUGU_API_KEY="YOUR_API_KEY"

curl -H "Authorization: Bearer $GUGU_API_KEY" https://api.gugu.app/v1/content
```

### Revoking an API Key

If a key is compromised or no longer needed, go to **Settings → API Keys**, find the key in the list, and click **Revoke**. The key stops working immediately.

<Warning>
  **Never expose your API key in public code repositories, client-side JavaScript, or shared documents.** Anyone who has your key can read and modify your Gugu content with your full account permissions. If you accidentally expose a key, revoke it immediately and generate a replacement.
</Warning>
